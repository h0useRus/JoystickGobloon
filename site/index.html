The problem

A HOTAS setup used to need three programs open at once

Each one has its own window, its own settings and its own way of failing. Joystick Gobloon replaces their user interfaces with one native app and talks to the same drivers directly.

Features

Everything your setup needs, in one fast app

Written in Rust, it reads controllers the moment they change and sits almost idle in the tray.

Keep the profile you already built

Import a Joystick Gremlin profile and it runs. Anything not supported yet is kept in the file, so nothing gets lost.

  • Modes with inheritance and per mode overrides
  • Map controls matches a profile from another PC to your devices in one click
  • Undo and redo for every edit

One button, four jobs with modifiers

Name a few buttons as modifiers. While M1 or M2 is held, every input with a layer for it runs that layer instead. Nothing gets stuck when you let go in the wrong order.

  • Layers for nothing, M1, M2 and M1 plus M2
  • Additive layers that run together with the base
  • Trim axes that keep their last value

Virtual joysticks without Configure vJoy

Create, change and remove vJoy devices from the app. Each one shows its axes, buttons and hats at a glance, and a built in tester moves them by hand.

  • Up to 16 devices, 8 axes, 128 buttons and 4 hats each
  • A new device starts as a copy of the first one

Games see only the virtual stick

Hide a physical controller with one click and stop double inputs for good. Joystick Gobloon still sees it, and you choose which other programs may too.

  • Switch hiding for the whole system from the toolbar or tray
  • HidHide inverse mode supported

See every input move live

Graphs of every axis, button and hat for physical sticks and vJoy devices alike, in the main window or a window of its own. Calibrate center and end points on the spot.

How it works

From download to flying in three steps

  1. Install

    Run the installer. It adds the signed HidHide and vJoy 2.1.9.1 drivers when they are missing. On Linux, start the AppImage and click Grant access once.

  2. Set up your profile

    Start a new profile, or import a Joystick Gremlin one from the toolbar. Made on another PC? Map controls matches it to your sticks.

  3. Hide and activate

    Hide the physical sticks with the eye button and press play. The game now sees only your virtual joysticks.

FAQ

Questions before you switch

Is Joystick Gobloon free?

Yes. It is open source under the MIT license. There is no account, no trial and nothing to buy.

Can I import my Joystick Gremlin profiles?

Yes. Open one from the toolbar and it runs. Anything not supported yet is kept as it was in the file.

Do I still need HidHide and vJoy installed?

You need the HidHide and vJoy drivers on Windows, and the installer adds them when they are missing. You do not need their own user interfaces.

Does it need administrator rights?

Only to install the drivers and when you change vJoy devices, with one UAC prompt per change. Everyday use runs as a normal user.

Does it run on the Steam Deck?

Yes, in desktop mode, like on any x86_64 Linux desktop. Make the AppImage executable, start it and click Grant access on the Devices page once.

Why does Windows SmartScreen warn on the first start?

Code signing through SignPath is being set up, and new releases need some downloads before SmartScreen trusts them. Choose More info, then Run anyway.

Is it ready for daily use?

It is in alpha. The daily features are in place and used every day with a dual stick setup, but expect rough edges. Bugs reported on GitHub get fixed quickly.

Can I try it without installing anything?

Use the portable zip: unpack it anywhere and start it. Delete the folder and it is gone. On Linux the AppImage is a single file.

Which languages does it speak?

English, Русский, Deutsch, Español, Français, 简体中文 and 한국어. Another language is one text file: copy lang/en.ftl, translate it and put it next to the app.
